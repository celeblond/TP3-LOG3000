# Module static

## Rôle
Contient les ressources statiques de l'application.

## Fichiers
- `style.css` : définit l'apparence et la disposition de la calculatrice, de l'affichage et des boutons.

## Dépendances et hypothèses
- Le fichier CSS est chargé par `templates/index.html` via Flask.
- Les sélecteurs correspondent aux éléments HTML de l'interface.
- La disposition des boutons utilise CSS Grid.
