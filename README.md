# Calculatrice web Flask — TP3 LOG3000

**Équipe :** 15  
**Cours :** LOG3000 — Processus du génie logiciel

## Objectif du projet

Ce projet contient une calculatrice web simple développée avec Python et Flask. L'application permet de saisir une expression arithmétique et d'en afficher le résultat dans une interface HTML/CSS.

Dans le cadre du TP3, l'équipe doit documenter le code existant, concevoir et exécuter des tests, suivre les bogues avec des Issues GitHub et appliquer un processus de correction par branches et Pull Requests.

## Prérequis

- Git
- Python 3 et `pip`
- Un navigateur web

## Installation

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/celeblond/TP3-LOG3000.git
   ```

2. Accéder au répertoire du projet :

   ```bash
   cd TP3-LOG3000
   ```

3. Installer Flask :

   ```bash
   python -m pip install Flask
   ```

4. Lancer l'application :

   ```bash
   python app.py
   ```

5. Ouvrir `http://127.0.0.1:5000/` dans un navigateur.

> Sur certains systèmes, il faut utiliser `python3` à la place de `python`.
